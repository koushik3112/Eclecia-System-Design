# ECLECIA Visual Design System

A responsive React + Vite + Tailwind CSS site for the ECLECIA design system.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (typically http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Features
- Responsive navigation and layout
- Brand color swatches with copy-to-clipboard
- Complementary accent color reference
- Typography scale and font pairings
- Interactive button-state preview
- Event card component preview
- Brochure, poster and social campaign examples
- Exportable CSS design tokens

## Notes
The color palette is a proposed working palette, not a verified official brand guideline. Validate official assets and color values before publication.
